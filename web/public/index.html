How sections are extracted

Each guide PDF is split at its canonical section headings using the PDF bookmarks. Freddie's Servicing segment is excluded. Current and future-effective Freddie versions are kept as separate records.

How changes are detected

Sections are matched across editions by number, then title, then text similarity, so renumbered or merged sections are not reported as deleted. Layout-only and editorial changes are separated from substantive revisions.

How guides are compared

Candidate counterparts come from a lexical and structural matcher. Human-reviewed pairs are shown first. Candidates are leads, not legal equivalence.

AI answers (optional)

This site works without AI. Running the optional server with an API key adds AI summaries for questions and changes, constrained to the retrieved text. See the README.
